# rc.32 and GPT-6 Astra

Local candidate; no remote push or production deployment was performed.

## Model configuration

The later [model-family discovery update](2026-09-05-model-family-discovery.md) allows base-only channel registration and pricing, with automatic alias discovery. The initial two-key guidance below describes the earlier Astra integration snapshot.

本版為 GPT-6 Astra 加入模型別名支援。呼叫格式為 `gpt-6-astra[-standard|-pro][-low|-medium|-high|-xhigh|-max]`，例如 `gpt-6-astra-pro-max` 代表 pro 模式搭配 max 推理強度。

渠道請同時設定 `gpt-6-astra` 與 `gpt-6-astra-*` 兩個模型鍵，前者承接基底請求，後者承接所有合法別名。別名沿用基底模型的價格設定，用量紀錄仍保留客戶端原始請求的模型名稱。

工具呼叫與推理模式需經 Responses API；請直接呼叫 `/v1/responses`，或在既有「Chat Completions 轉 Responses」設定中加入 Astra 的模型比對規則，閘道不會自動改寫端點。Astra 由內建 OpenAI adaptor 提供，閘道會移除 temperature、top_p、top_logprobs，Chat 另移除 logprobs，Responses 的 include 會剔除 `message.output_text.logprobs`。

預設倍率對應標準短上下文價格：每百萬 tokens 輸入 10 美元、輸出 50 美元、快取讀取 1 美元、快取寫入 12.5 美元。長上下文與快速層級價格需管理者透過計費表達式自行設定。本版尚未部署至正式環境。
