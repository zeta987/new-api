# v1.0.0-rc.26 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The user explicitly requires execution in the primary checkout without a linked worktree. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate upstream `v1.0.0-rc.26`, preserve all released rc.25 customizations as four clean rc.26 backup themes, migrate the production PostgreSQL wallet schema when required, and verify a signed rc.26 deployment.

**Architecture:** The release branch starts from the signed rc.25 integrated release and receives a signed non-fast-forward merge of the verified upstream rc.26 tag. The integrated release keeps all released behavior, while each reusable backup branch is independently rebuilt from the clean rc.26 tag by replaying exactly one rc.25 theme commit and resolving only its theme-local delta. Production remains on rc.25 until the database, tests, signatures, remote refs, and exact release confirmation gate are complete.

**Tech Stack:** Go 1.22+, GORM v2, PostgreSQL, SQLite, MySQL, React 19, TypeScript 7 native preview, Rsbuild, Bun, Vitest, Git signed commits, Zeabur CLI.

**Spec:** `docs/superpowers/specs/2026-08-26-rc26-upgrade-design.md`
